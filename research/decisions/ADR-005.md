first repository landing page disconnected from the supplied visual laboratory.

immutable UI commit `0afc064f145641d472f063fc4c66d07dd584ba80` into the research

## Verification and resources

Inspect the committed code and provenance before running local checks. Verify
the five vendored contract files against frozen v1. Run the four frontend unit
test files and the contract validator, then build and validate one disposable
static package using the existing runtime. Do not run deployment, DNS, OAuth or
Search Console helpers. No package installation, browser download or cloud work
is needed. Use one foreground process at a time, a 60-second per-command timeout
and a 100 MiB package bound. Preserve failed attempts rather than deleting them.

The initial history audit covers all objects reachable from the research code
freeze and the selected UI head. It found no matches for the declared credential
patterns or unwanted attribution trailers. This bounded scan does not certify
the absence of every secret. Refresh the audit on the eventual publication head.
Keep source papers outside Git and retain only source metadata and original analysis.

## Licensing and publication

The proposed software/documentation choice is Apache-2.0, with MIT and proprietary
distribution presented as alternatives. The operator's pending choice will decide
the grant. A public site authorization does not silently license concept media,
brand marks or third-party work under a software license. Preserve their registry
and separate their rights explicitly in the final licensing notice.

Do not create a remote, publish or change visibility until those choices resolve.
Then inspect the exact staged/reachable contents and commit messages, preserve
Daniel's identity, push without rewriting history, and read back the remote head,
visibility and license. Local validation cannot stand in for that readback.

New observation/interface study records remain separate from the UI's synthetic
v1 fixture. This integration does not create an analytical adapter or turn the
concept imagery into hardware evidence. A failed contract comparison, unexpected
scope change or credential finding stops release preparation for correction.
