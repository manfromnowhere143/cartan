## Browser and accessibility sources

Reviewed the primary specifications and vendor documentation:

- [CSS View Transitions Level 1](https://www.w3.org/TR/css-view-transitions-1/):
  document snapshots do not establish support for scoped element transitions.
- [Chrome element-scoped transitions](https://developer.chrome.com/docs/css-ui/view-transitions/element-scoped-view-transitions/),
  published 27 March 2026, describes Chrome 147+ and element-level scopes.
- [WebKit Safari 18 features](https://webkit.org/blog/15865/webkit-features-in-safari-18-0/)
  documents View Transitions and unprefixed backdrop filtering; it is not evidence
  that the installed Safari supports element-scoped transitions.
- [Filter Effects Level 2](https://www.w3.org/TR/filter-effects-2/): filtering is an
  optional rendering effect. CARTAN's text uses an opaque surface without it.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): review reflow, contrast, visible and
  unobscured focus, keyboard access and target sizes; no conformance certification
  follows from source or DOM checks.
- [WAI modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/):
  focus enters the existing native film dialog, Escape dismisses, and focus returns
  to its opener. The interior is not modal and must not trap focus.
