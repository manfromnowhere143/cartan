## Decision and alternatives

Retain the opening markup, typography, media controller and original assets.
Use a single persistent, code-drawn module schematic beside the active interior
reading surface. Selection changes emphasis; interface detail exposes a separate
relationship diagram; interrupted state leaves the scene unchanged and presents
the two possibilities in the pinned fixture. No mechanical animation is justified.
The scene is an explanatory arrangement, not a reconstruction of the film or CAD.
Native scroll carries long text and small-screen reading. It is never a slide deck.

Use instantaneous, synchronous state commits first. No View Transition, WebGL,
blur, glass or animation is needed for this slice. Opaque near-black material is
the legibility and low-power baseline, including when filters are unsupported.
Reject full-document transitions (previous flashing), a second renderer (no
qualified geometry), and photographic part hotspots (would assert unverified
correspondence). A future scoped transition must beat this instant path in measured
use; support alone is not a reason to add it.

URL path and allowlisted query parameters own view, part, interface disclosure
and evidence selection. Native links carry these states; one commit function
updates the scene, content, metadata and focus. Back restores the previous state
and its focus/reading position; Escape follows the containing view. Existing
legacy hashes and eight static routes remain. No asynchronous reveal can commit
a stale selection. Fixture arrival only fills provenance and fixture fields.

## Bound and rejection criteria

opening paint; use inline SVG and defer the pinned fixture until inspection.
