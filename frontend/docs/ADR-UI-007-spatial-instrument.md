## Design decision before implementation

Make the object the main field. A permanent scene, compact reading instrument,
four function selectors, three viewing presets and one contextual evidence route
replace the visual balance of an illustration beside a long article. All existing
crawlable URLs remain aliases for states in this single document. No slide deck,
page wipe, decorative telemetry, star field, ambient particles or animated grain.

Use original dimensionless, inspectable 3D geometry to explain the existing three
relationships: host, module and independent support. A separate electrical boundary
is an explanatory marker, not a connector design. Explicitly label every view
spatial schematic / geometry unverified. No bolts, real connector pins, internal
electronics, dimensions, mass, validated engagement travel or physical simulation.
Diagram separation is a graphic layout operation, never an actuation sequence.

A native WebGL2 enhancement supplies depth testing, lit bevelled surfaces and
direct geometry selection. A projected SVG from the same mesh supplies a complete
fallback and native DOM buttons supply the same actions. No Three.js, WebGPU stack,
model download, HDR environment, texture or framework is necessary for this bounded
scene. Load renderer code only on interior entry. Stop at rest; render on interaction
or resize. Camera motion, if present, lasts at most 320ms and cancels immediately
on newer input, route exit or reduced motion. No physical part motion is inferred.

Retain the original text, fixture and scientific distinctions inside one reading
surface. On sufficiently large windows it scrolls independently while the module
stays visible. On narrow/short windows use normal document reflow and scroll.
Solid reading material is the baseline. Glass/refraction and post-processing do
not improve the actual inspection task and are not selected for this revision.

## Resource and falsification bounds

No dependency install, paid work, new model/agent, Engine import or deployment.
Target <50 kB of lazy scene code and <2,000 triangles; one canvas, DPR capped at
1.5 and total pixel budget capped. One drawing at rest, no permanent RAF loop.
All old media and frozen v1 bytes remain. Preserve the existing setup change.

Reject if selected surfaces cannot be identified, camera input changes scientific
state, context loss blanks the workspace, reduced motion loses actions, a slow
import revives a departed view, or native history/focus diverges from the URL.
Test geometry, projection/picking, bounded lifecycle, same-mesh fallbacks, direct
URLs and existing sequence/contract/package gates. Retain actual measurements.
Both native and browser bridges still fail this turn; therefore GPU/browser/phone
acceptance and visual layout remain unverified unless access actually returns.
